■ 手順2：.env の設定（初心者向け）

【すでにやったこと】
・.env ファイルは server フォルダに作成済みです。

【あなたがやること】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. アプリパスワードを Gmail で取る（まだの場合）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ブラウザで https://myaccount.google.com/ を開く
2. ailand.510.ai.send@gmail.com でログイン
3. 左の「セキュリティ」
4. 「2段階認証プロセス」がオフならオンにする
5. 検索欄に「アプリ パスワード」と入力して開く
   ※出ない場合: https://myaccount.google.com/apppasswords
6. アプリ名「メール」、デバイス「Windows」など → 作成
7. 表示された 16文字（例: abcd efgh ijkl mnop）をメモ

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
B. .env ファイルを編集する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Cursor で左のフォルダから開く:
   rentcar-site → server → .env

2. 次の1行だけ書き換える:

   GMAIL_APP_PASSWORD=your-16-char-app-password
        ↓
   GMAIL_APP_PASSWORD=abcdefghijklmnop
   （メモした16文字。スペースは入れても入れなくてもOK）

3. 保存（Ctrl + S）

※ GMAIL_SENDER はすでに ailand.510.ai.send@gmail.com になっています
※ API_SECRET はそのままでも動きます

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
C. npm install（初回だけ）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Cursor 上部メニュー「ターミナル」→「新しいターミナル」
2. 次をコピーして Enter:

   cd C:\Users\mizuk\rentcar-site\server
   npm install

   （1〜2分かかることがあります）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
D. サーバー起動
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   npm start

「Rentcar mail server (SMTP)」と出れば成功。

ブラウザで開く:
   http://localhost:3001/api/health

   mailConfigured が true なら OK。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【よくある間違い】
× Gmail の普通のログインパスワードを入れる
○ アプリパスワードの16文字を入れる

× .env.example を編集する
○ .env を編集する
