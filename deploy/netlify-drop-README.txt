レンタカー予約サイト（Netlify 用）

■ このフォルダを Netlify Drop にドラッグ
  https://app.netlify.com/drop

■ チームに共有する URL
  - 予約サイト: https://（表示されたURL）/index.html
  - 管理者: https://（表示されたURL）/admin.html

  - admin.html にパスワードはありません。URLはチーム内だけで共有してください
