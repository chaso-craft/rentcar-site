# GOTO rental car

五島・福江島のレンタカー予約サイトと、店舗管理サイトです。

## 開き方

1. `index.html` をブラウザで開く（予約サイト）
2. 画面下の「店舗管理」または `admin.html` を開く（管理サイト）

ショートカット:

- `shortcuts/レンタカー予約サイト.url`
- `shortcuts/レンタカー管理者サイト.url`

## 予約サイトでできること

- 貸出・返却日時の空き検索（30分刻み）
- 車種の確認と予約
- オプション・料金見積もり
- キャンセルポリシー同意後の予約確定

## 管理サイトでできること

- ログイン（初期パスワード: `admin`）
- ダッシュボード（未読・当日予約・未払い）
- 予約カレンダーとスケジュール
- 予約の状態・支払・既読管理
- 車両の在庫・紹介文の編集（予約サイトへ即反映）
- 店舗名・住所・紹介文の編集
- 見積書・領収書の検索と印刷

## データの保存場所

- **Supabase 設定済み**（`supabase-config.js` に anon キーあり）: 予約・設定はクラウドに保存され、管理者サイトで全員の予約を確認できます。手順は `SETUP-SUPABASE.md` を参照。
- **未設定**: 従来どおりブラウザの LocalStorage（端末ごとに別データ）です。

## メール送信

本番では Supabase Edge Function（`send-confirmation`）から Gmail で送信します。  
ローカル検証用の Node サーバーは `server/README.md` を参照してください。
